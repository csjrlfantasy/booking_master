## 1. 技术架构

### 1.1 技术栈选型

#### 1.1.1 核心框架

| 技术 | 选型 | 版本 | 说明 |
|------|------|------|------|
| **跨平台框架** | React Native | 0.76.x | Facebook开源，生态成熟，热更新支持好 |
| **原生语言** | TypeScript | 5.x | 类型安全，IDE支持好 |
| **构建工具** | React Native CLI | 最新稳定版 | 比Expo更灵活，支持原生模块定制 |
| **包管理器** | npm + yarn | - | 混合使用，利用各自优势 |

**选型理由**：
- React Native 0.76版本已内置TypeScript支持，无需额外配置
- 采用新架构（Fabric Renderer），性能更优
- 社区生态丰富，第三方库支持度高
- 相比Flutter，学习成本更低，团队上手快

#### 1.1.2 状态管理

| 模块 | 技术 | 版本 | 说明 |
|------|------|------|------|
| **全局状态** | Redux Toolkit | 2.x | 官方推荐，Redux最佳实践 |
| **异步状态** | Redux Toolkit Query | 2.x | 数据获取、缓存、自动重试 |
| **本地状态** | React Context | 内置 | 轻量级状态共享 |
| **表单状态** | React Hook Form | 7.x | 高性能表单处理 |
| **持久化** | Redux Persist + MMKV | - | 高性能本地存储 |

**选型理由**：
- Redux Toolkit简化Redux使用，减少样板代码
- RTK Query内置缓存机制，减少网络请求
- MMKV比AsyncStorage性能高10倍以上

**Button组件示例**：
```typescript
// components/common/Button.tsx
interface ButtonProps {
  variant: 'primary' | 'secondary' | 'outline' | 'text';
  size: 'small' | 'medium' | 'large';
  loading?: boolean;
  disabled?: boolean;
  icon?: ReactNode;
  children: ReactNode;
  onPress: () => void;
  style?: ViewStyle;
  fullWidth?: boolean;
}

const Button: React.FC<ButtonProps> = ({
  variant = 'primary',
  size = 'medium',
  loading = false,
  disabled = false,
  icon,
  children,
  onPress,
  style,
  fullWidth = false,
}) => {
  const isDisabled = disabled || loading;
  
  const getBackgroundColor = () => {
    if (isDisabled) return colors.disabled;
    switch (variant) {
      case 'primary': return colors.primary;
      case 'secondary': return colors.secondary;
      case 'outline': return 'transparent';
      case 'text': return 'transparent';
      default: return colors.primary;
    }
  };

  return (
    <TouchableOpacity
      style={[
        styles.button,
        { backgroundColor: getBackgroundColor() },
        fullWidth && styles.fullWidth,
        style,
      ]}
      onPress={onPress}
      disabled={isDisabled}
      activeOpacity={0.8}
    >
      {loading ? (
        <ActivityIndicator color={colors.white} />
      ) : (
        <>
          {icon && <Icon name={icon} size={size} color={getTextColor()} />}
          <Text style={[styles.text, { color: getTextColor() }]}>
            {children}
          </Text>
        </>
      )}
    </TouchableOpacity>
  );
};
```

```typescript
// store/slices/cartSlice.ts
import { createSlice, PayloadAction } from '@reduxjs/toolkit';

interface CartItem {
  id: string;
  ticketId: string;
  ticketName: string;
  venueName: string;
  showTime: string;
  price: number;
  priceLevel: string;
  quantity: number;
  seatCode?: string;  // 已选座位
  imageUrl?: string;
}

interface CartState {
  items: CartItem[];
  selectedIds: string[];
  totalAmount: number;
  totalCount: number;
}

const initialState: CartState = {
  items: [],
  selectedIds: [],
  totalAmount: 0,
  totalCount: 0,
};

const cartSlice = createSlice({
  name: 'cart',
  initialState,
  reducers: {
    addToCart: (state, action: PayloadAction<CartItem>) => {
      const existingIndex = state.items.findIndex(
        item => item.ticketId === action.payload.ticketId
      );
      if (existingIndex >= 0) {
        state.items[existingIndex].quantity += action.payload.quantity;
      } else {
        state.items.push(action.payload);
      }
      recalculateTotal(state);
    },
    removeFromCart: (state, action: PayloadAction<string>) => {
      state.items = state.items.filter(item => item.id !== action.payload);
      state.selectedIds = state.selectedIds.filter(id => id !== action.payload);
      recalculateTotal(state);
    },
    updateQuantity: (state, action: PayloadAction<{ id: string; quantity: number }>) => {
      const item = state.items.find(i => i.id === action.payload.id);
      if (item) {
        item.quantity = action.payload.quantity;
      }
      recalculateTotal(state);
    },
    toggleSelect: (state, action: PayloadAction<string>) => {
      const index = state.selectedIds.indexOf(action.payload);
      if (index >= 0) {
        state.selectedIds.splice(index, 1);
      } else {
        state.selectedIds.push(action.payload);
      }
    },
    selectAll: (state) => {
      state.selectedIds = state.items.map(item => item.id);
    },
    clearSelection: (state) => {
      state.selectedIds = [];
    },
    clearCart: (state) => {
      state.items = [];
      state.selectedIds = [];
      state.totalAmount = 0;
      state.totalCount = 0;
    },
  },
});

const recalculateTotal = (state: CartState) => {
  const selectedItems = state.items.filter(item => 
    state.selectedIds.includes(item.id)
  );
  state.totalAmount = selectedItems.reduce(
    (sum, item) => sum + item.price * item.quantity, 
    0
  );
  state.totalCount = selectedItems.reduce(
    (sum, item) => sum + item.quantity, 
    0
  );
};

export const { 
  addToCart, 
  removeFromCart, 
  updateQuantity, 
  toggleSelect, 
  selectAll, 
  clearSelection, 
  clearCart 
} = cartSlice.actions;

export default cartSlice.reducer;
```

```typescript
  useEffect(() => {
    const showEvent = Platform.OS === 'ios' ? 'keyboardWillShow' : 'keyboardDidShow';
    const hideEvent = Platform.OS === 'ios' ? 'keyboardWillHide' : 'keyboardDidHide';
    
    const showListener = Keyboard.addListener(showEvent, (e) => {
      setKeyboardHeight(e.endCoordinates.height);
    });
    
    const hideListener = Keyboard.addListener(hideEvent, () => {
      setKeyboardHeight(0);
    });
    
    return () => {
      showListener.remove();
      hideListener.remove();
    };
  }, []);
  
  return {
    top: insets.top,
    bottom: insets.bottom,
    left: insets.left,
    right: insets.right,
    keyboardHeight,
    keyboardVisible: keyboardHeight > 0,
  };
};

// 横竖屏适配
export const useOrientation = () => {
  const { width, height } = Dimensions.get('window');
  const isLandscape = width > height;
  
  return { isLandscape, isPortrait: !isLandscape };
```

```typescript
// services/analytics/AnalyticsService.ts
import { 
  umengTrack, 
  umengPageView,
  umengError,
} from '@/native/UMengModule';

export interface TrackEvent {
  eventId: string;
  eventName: string;
  params?: Record<string, any>;
  timestamp?: number;
  duration?: number;  // 事件时长
}

class AnalyticsService {
  private queue: TrackEvent[] = [];
  private isFlushing = false;
  
  // 初始化
  init() {
    // 友盟初始化
    umengTrack.init({
      appKey: Config.UMENG_APP_KEY,
      debugMode: __DEV__,
    });
    
    // 设置推送通道
    umengTrack.setPushChannel('default');
    
    // 开启页面自动统计
    umengTrack.setAutoPageTrack(true);
  }
  
  // 页面进入
  pageEnter(pageName: string, params?: object) {
    umengPageView.onPageBegin(pageName);
    
    this.track('page_view', {
      page: pageName,
      ...params,
    });
  }
  
  // 页面离开
  pageLeave(pageName: string, duration?: number) {
    umengPageView.onPageEnd(pageName);
    
    if (duration) {
      this.track('page_stay', {
        page: pageName,
        duration,
      });
    }
  }
  
  // 事件埋点
  track(eventId: string, params?: Record<string, any>) {
    const event: TrackEvent = {
      eventId,
      eventName: eventId,
      params,
      timestamp: Date.now(),
    };
    
    // 友盟上报
    umengTrack.trackEvent(eventId, params);
    
    // 队列缓存（离线场景）
    this.queue.push(event);
    this.flushQueue();
  }
  
  // 特定事件
  trackLogin(method: 'phone' | 'wechat' | 'apple') {
    this.track('user_login', { method, platform: Platform.OS });
  }
  
  trackPurchase(orderId: string, amount: number, items: number) {
    umengTrack.trackPurchase({
      orderId,
      amount,
      currency: 'CNY',
      itemQuantity: items,
    });
  }
  
  trackSearch(keyword: string, resultCount: number) {
    this.track('search', { keyword, resultCount });
  }
  
  trackTicketView(ticketId: string, ticketName: string) {
    this.track('ticket_view', { ticketId, ticketName });
  }
  
  trackSeatSelect(venueId: string, seatCount: number) {
    this.track('seat_select', { venueId, seatCount });
  }
  
  trackPayment(method: 'wechat' | 'alipay' | 'card', amount: number) {
    this.track('payment', { method, amount });
  }
  
  // 错误上报
  reportError(error: Error, extra?: object) {
    umengError.reportError(error.message, {
      stack: error.stack,
      ...extra,
    });
  }
  
  // 队列刷新
  private flushQueue() {
    if (this.isFlushing || this.queue.length === 0) return;
    
    this.isFlushing = true;
    
    // 批量上报
    const events = this.queue.splice(0, 20);
    this.batchTrack(events);
    
    this.isFlushing = false;
  }
  
  private batchTrack(events: TrackEvent[]) {
    // 调用埋点接口
    api.post('/v2/track', { events }).catch(() => {
      // 上报失败，放回队列
      this.queue.unshift(...events);
    });
  }
}

export const analytics = new AnalyticsService();
```

```markdown
- **组件路径**: `src/components/common/Button.tsx`
- **组件类型**: 基础组件
- **支持平台**: iOS / Android
- **依赖**: 无

## 功能描述
简要描述组件的功能和使用场景。

## Props

| 属性名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| variant | 'primary' \| 'secondary' | 否 | 'primary' | 按钮变体 |
| size | 'small' \| 'medium' \| 'large' | 否 | 'medium' | 按钮尺寸 |
| loading | boolean | 否 | false | 加载状态 |
| disabled | boolean | 否 | false | 禁用状态 |
| onPress | () => void | 是 | - | 点击回调 |

## 使用示例

\`\`\`tsx
import Button from '@/components/common/Button';

// 基本使用
<Button onPress={() => console.log('click')}>
  确认
</Button>

// 加载状态
<Button loading onPress={handleSubmit}>
  提交中
</Button>
\`\`\`

## 注意事项
- 使用时注意设置onPress回调
- 避免在组件内嵌套其他组件
```

```markdown
# 接口名称

## 基本信息
- **接口路径**: `/api/v1/tickets`
- **请求方式**: GET
- **鉴权**: 是

## 请求参数

### Query参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | number | 否 | 页码，默认1 |
| pageSize | number | 否 | 每页数量，默认20 |
| category | string | 否 | 分类ID |
| keyword | string | 否 | 搜索关键词 |

## 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | number | 状态码 |
| message | string | 提示信息 |
| data | object | 数据对象 |
| data.list | Ticket[] | 票品列表 |
| data.total | number | 总数 |
| data.page | number | 当前页码 |
| data.pageSize | number | 每页数量 |

### Ticket对象

| 参数名 | 类型 | 说明 |
|--------|------|------|
| id | string | 票品ID |
| name | string | 票品名称 |
| venue | string | 场馆名称 |
| showTime | string | 演出时间 |
| minPrice | number | 最低价 |
| maxPrice | number | 最高价 |
| coverImage | string | 封面图 |

## 错误码

| 错误码 | 说明 |
|--------|------|
| 1001 | 参数错误 |
| 1002 | 未登录 |
| 5000 | 服务器内部错误 |
```
