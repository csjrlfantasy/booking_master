### 6.1 执行阶段划分

| 阶段 | 阶段名称 | 执行内容 | 优先级 | 预计工时 |

| Phase 1 | 冒烟测试 | 核心P0用例快速验证 | P0 | 30min |

## 7. 缺陷等级定义

### 7.1 缺陷严重等级

| 等级 | 等级名称 | 定义 | 影响范围 | 处理时限 |
|-----|---------|------|---------|---------|
| **P0 - Critical** | 致命缺陷 | 系统无法运行或核心功能完全不可用 | 全部用户 | 立即处理 |
| **P1 - Major** | 严重缺陷 | 核心功能存在严重问题，导致主要流程无法完成 | 大部分用户 | 24小时内 |
| **P2 - Moderate** | 中等缺陷 | 功能存在问题，但存在替代方案或影响范围有限 | 部分用户 | 72小时内 |
| **P3 - Minor** | 轻微缺陷 | 轻微问题，不影响功能使用，界面展示问题 | 少量用户 | 下一迭代 |

### 7.2 缺陷优先级

| 优先级 | 定义 | 说明 |
|-------|------|------|
| **P0 - Urgent** | 紧急 | 必须立即修复 |
| **P1 - High** | 高 | 应该在当前迭代修复 |
| **P2 - Medium** | 中 | 应该在下一迭代修复 |
| **P3 - Low** | 低 | 可以延后处理 |

### 7.3 缺陷状态流转

```
新建 → 确认 → 分配 → 修复中 → 已修复 → 待验证 → 关闭
  │       │        │        │        │        │       │
  │       └────────┴────────┴────────┘        │       │
  │                                             │       │
  └─────────────────────────────────────────────┘       │
                        重新打开                             
```
