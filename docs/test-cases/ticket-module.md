### TC1001: 票务列表-正常分页查询

| 项目 | 内容 |
|------|------|
| **用例编号** | TC1001 |
| **用例名称** | 票务列表-正常分页查询 |
| **测试目的** | 验证票务列表能够正常分页返回数据 |
| **优先级** | P0 |
| **前置条件** | 数据库中存在至少20条票务数据 |
| **测试步骤** | 1. 构造分页请求<br>2. GET请求到 `/ticket/list?pageNum=1&pageSize=20` |

**请求参数：**
```
GET /ticket/list?pageNum=1&pageSize=20
```

**预期结果：**
- [ ] HTTP状态码为 200
- [ ] 响应体 `code` 为 0
- [ ] 响应体 `data` 包含分页信息：
  - `list`: 数组，长度≤20
  - `total`: 总数，正整数
  - `pageNum`: 1
  - `pageSize`: 20
- [ ] `list` 中每条记录包含必要字段：
  - `ticketId`: 正整数
  - `name`: 字符串
  - `poster`: 字符串（URL或null）
  - `venueName`: 字符串
  - `showDate`: 字符串
  - `minimumPrice`: 数字
  - `maximumPrice`: 数字
  - `status`: 整数
  - `statusName`: 字符串

**响应示例：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [
      {
        "ticketId": 1,
        "name": "周杰伦2026世界巡回演唱会",
        "subName": "上海站",
        "poster": "https://example.com/poster/1.jpg",
        "venueName": "梅赛德斯奔驰文化中心",
        "showDate": "2026-05-01",
        "showTime": "19:30",
        "minimumPrice": 380,
        "maximumPrice": 1980,
        "status": 1,
        "statusName": "售票中",
        "saleCount": 8500,
        "isHot": true,
        "tags": ["演唱会", "热门"]
      }
    ],
    "total": 50,
    "pageNum": 1,
    "pageSize": 20
  },
  "timestamp": 1712832000000
```
