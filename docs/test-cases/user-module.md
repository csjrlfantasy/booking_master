## 功能测试用例

### TC001: 用户注册-正常注册

| 项目 | 内容 |
|------|------|
| **用例编号** | TC001 |
| **用例名称** | 用户注册-正常注册 |
| **测试目的** | 验证用户能够成功完成注册流程 |
| **优先级** | P0 |
| **前置条件** | 数据库中不存在用户名 `testuser001` 和手机号 `13800000001` |
| **测试步骤** | 1. 构造注册请求，填写所有必填字段<br>2. POST请求到 `/api/user/register`<br>3. 记录返回的 userId |

**请求数据：**
```json
{
  "username": "testuser001",
  "password": "Pass1234",
  "phone": "13800000001",
  "email": "testuser001@example.com",
  "nickname": "测试用户001",
  "source": "app"
}
```

**预期结果：**
- [ ] HTTP状态码为 200
- [ ] 响应体 `code` 为 0
- [ ] 响应体 `message` 为 "success"
- [ ] 响应体 `data` 为正整数（userId）
- [ ] 数据库中存在对应的用户记录

**响应示例：**
```json
{
  "code": 0,
  "message": "success",
  "data": 1,
  "timestamp": 1712832000000
}
```

### TC010: 用户登录-连续失败5次账户锁定

| 项目 | 内容 |
|------|------|
| **用例编号** | TC010 |
| **用例名称** | 用户登录-连续失败5次账户锁定 |
| **测试目的** | 验证连续登录失败5次后账户被锁定30分钟 |
| **优先级** | P0 |
| **前置条件** | 存在已注册用户，用户名 `testuser001`，密码 `Pass1234`，且登录失败次数为0 |
| **测试步骤** | 1. 使用错误的密码连续登录5次<br>2. 第6次使用正确密码尝试登录 |

**测试步骤详情：**

| 步骤 | 操作 | 预期结果 |
|-----|------|---------|
| 1 | 第1次错误密码登录 | 登录失败，失败次数=1 |
| 2 | 第2次错误密码登录 | 登录失败，失败次数=2 |
| 3 | 第3次错误密码登录 | 登录失败，失败次数=3 |
| 4 | 第4次错误密码登录 | 登录失败，失败次数=4 |
| 5 | 第5次错误密码登录 | 登录失败，失败次数=5，账户未锁定 |
| 6 | 第6次错误密码登录 | 登录失败，**账户被锁定30分钟**，失败次数=6 |
| 7 | 正确密码尝试登录 | 登录失败，返回锁定提示 |

**预期结果（第6次错误登录后）：**
- [ ] HTTP状态码为 200
- [ ] 响应体 `code` 为 100110（USER_LOGIN_LOCKED）
- [ ] 响应体 `message` 包含 "账号已被锁定" 或 "30分钟"
- [ ] 数据库中 `lock_until` 字段被设置为当前时间+30分钟

**预期结果（锁定后尝试正确密码）：**
- [ ] HTTP状态码为 200
- [ ] 响应体 `code` 为 100110（USER_LOGIN_LOCKED）
- [ ] 响应体 `message` 包含 "账号已被锁定"
