## 购物车API测试用例

### TC-CART-001: 购物车-添加商品

| 项目 | 内容 |
|------|------|
| **用例编号** | TC-CART-001 |
| **用例名称** | 购物车-添加商品 |
| **测试目的** | 验证用户可以将票品添加到购物车 |
| **优先级** | P0 |
| **前置条件** | 用户已登录，票品有库存 |
| **测试步骤** | 1. 登录获取Token<br>2. POST请求到 `/cart`<br>3. 验证响应 |

**请求参数：**
```
POST /api/cart
Content-Type: application/json
Authorization: Bearer {token}

{
  "ticketId": 1,
  "skuId": 101,
  "quantity": 2
}
```

**预期结果：**
- [ ] HTTP状态码为 200
- [ ] 响应体 `code` 为 0
- [ ] 响应体 `data` 包含购物车商品信息
- [ ] 返回购物车商品总数

**响应示例：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "cartId": 1,
    "userId": 1,
    "totalItems": 2,
    "totalAmount": 760.00
  },
  "timestamp": 1714310400000
}
```
