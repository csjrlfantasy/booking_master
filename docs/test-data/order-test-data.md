## 6. 接口测试参数矩阵

### 6.1 添加购物车参数

| 参数名 | 类型 | 必填 | 有效值 | 无效值 |
|--------|------|------|--------|--------|
| ticketId | Long | 是 | 1, 2, 3 | 0, -1, 999999, "abc" |
| skuId | Long | 是 | 101, 102, 103 | 0, -1 |
| quantity | Integer | 是 | 1~10 | 0, -1, 11, 100 |

### 6.2 创建订单参数

| 参数名 | 类型 | 必填 | 有效值 | 无效值 |
|--------|------|------|--------|--------|
| cartItemIds | List | 是(购物车购买) | [1, 2] | [], null |
| ticketId | Long | 是(立即购买) | 1, 2, 3 | 0, 999999 |
| skuId | Long | 是(立即购买) | 101, 102 | 0 |
| quantity | Integer | 是 | 1~限购数 | 0, -1, 超过限购 |
| couponId | String | 否 | "COUP001" | "INVALID", "EXPIRED" |
| remark | String | 否 | "备注信息" | 超过500字符 |

### 6.3 分页参数

| 参数名 | 类型 | 默认值 | 有效范围 | 边界值 |
|--------|------|--------|----------|--------|
| page | Integer | 1 | 1~max | 0, -1, 9999 |
| pageSize | Integer | 10 | 1~100 | 0, -1, 1000 |
