## 二、后端安全检查

### 2.1 JWT Token安全 ⭐ Sprint 2 重点

| 检查项 | 检查标准 | 优先级 | 状态 | 备注 |
|--------|---------|--------|------|------|
| 密钥配置 | 必须从环境变量/配置中心获取 | 必检 | ☐ | |
| 密钥默认值 | 禁止硬编码默认值 | 必检 | ☐ | |
| 密钥强度 | 长度不少于32字节 | 必检 | ☐ | |
| 过期时间 | 不超过24小时 | 必检 | ☐ | |

**检查代码示例：**
```java
// ✅ 正确
@Value("${jwt.secret}")
private String secret;

@PostConstruct
public void validateSecret() {
    if (secret == null || secret.length() < 32) {
        throw new IllegalStateException("JWT密钥配置不正确");
    }
}

// ❌ 错误 - 硬编码默认值
@Value("${jwt.secret:weak-default-secret}")
private String secret;
```

### 2.2 SQL注入防护 ⭐ Sprint 2 重点

| 检查项 | 检查标准 | 优先级 | 状态 | 备注 |
|--------|---------|--------|------|------|
| 参数化查询 | 必须使用#{}语法 | 必检 | ☐ | |
| LIKE转义 | LIKE中的特殊字符需转义 | 必检 | ☐ | |
| 字符串拼接 | 禁止SQL字符串拼接 | 必检 | ☐ | |

**检查代码示例：**
```xml
<!-- ✅ 正确 - 转义特殊字符 -->
<if test="keyword != null and keyword != ''">
    AND name LIKE CONCAT('%', REPLACE(REPLACE(#{keyword}, '%', '\\%'), '_', '\\_'), '%')
</if>

<!-- ❌ 错误 - 未转义 -->
<if test="keyword != null and keyword != ''">
    AND name LIKE '%${keyword}%'
</if>
```

## 五、订单模块专项检查 ⭐ Sprint 3 重点

### 5.1 并发控制

| 检查项 | 检查标准 | 优先级 | 状态 | 备注 |
|--------|---------|--------|------|------|
| 库存校验 | 下单前必须校验库存 | 必检 | ☐ | |
| 原子操作 | 库存扣减使用原子操作 | 必检 | ☐ | |
| 分布式锁 | 高并发场景使用分布式锁 | 必检 | ☐ | |
| 乐观锁 | 可选：版本号控制 | 建议 | ☐ | |

**检查代码示例：**
```java
// ✅ 正确 - 使用分布式锁
@DistributedLock(key = "order:stock:{ticketId}")
public void createOrder(Long ticketId, Integer quantity) {
    // 校验+扣减+创建订单
}

// ✅ 正确 - 乐观锁
@Update("UPDATE ticket SET available_stock = available_stock - #{quantity}, version = version + 1 WHERE id = #{id} AND version = #{version} AND available_stock >= #{quantity}")

// ❌ 错误 - 先查后改（非原子）
Ticket ticket = ticketRepository.selectById(id);
if (ticket.getStock() >= quantity) {
    ticket.setStock(ticket.getStock() - quantity); // 并发问题
    ticketRepository.update(ticket);
}
```
