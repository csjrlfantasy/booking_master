### 2.2 代码分析

#### BUG-006 分析

**接口**: POST /api/orders

**复现请求**:
```json
{
  "ticketId": 4,
  "sessionId": 1,
  "contactName": "TestUser",
  "contactPhone": "13800138000",
  "items": [
    {
      "priceLevelId": 1,
      "priceLevelName": "VIP",
      "quantity": 2,
      "unitPrice": 680.00
    }
  ]
}
```

**返回**: `{"code":200100,"message":"系统繁忙，请稍后再试"}`

**已实现代码分析** (OrderServiceImpl.java):

1. 订单创建逻辑已实现（行55-171）：
   - 生成订单号
   - 查询票务信息
   - 计算金额
   - 使用优惠券
   - 创建订单和订单明细

2. 可能问题点：
   - ticketRepository.selectTicketDetailById() 返回null
   - session数据不存在
   - 数据库连接异常

#### BUG-008 分析

**接口**: 
- GET /api/cart

**返回**: `{"code":200100,"message":"系统繁忙，请稍后再试"}`
